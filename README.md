# Target

Target is an offline Android app for exam preparation, study tracking and reading. It has no internet permission, and all data is stored locally on the device.

## Features

- **Exam prep:** Exams with optional sections, courses, languages, topics and study resources.
- **Progress tracking:** Practice sessions and practice exams, with correct/wrong/blank counts, net score and remaining targets.
- **Statistics:** Trend charts, accuracy, pace and per-topic breakdowns.
- **Planner:** Week, month and year views, recurring events and reminders.
- **Focus Timer:** Custom work/break presets, session history and manual logging.
- **Reading:** Book library, page tracking, finish-date forecasts and daily reading goals.
- **Other:** Multiple local accounts, English and Turkish, light/dark themes, and CSV export/import.

## Tech Stack

Kotlin, Jetpack Compose, Material 3, Room, Navigation Compose.

## Build

```
./gradlew assembleDebug
```
